## Commands

| Command | Description | Typical Use |
| --- | --- | --- |
| `/play` | Plays audio from search or direct URL. | Start playback |
| `/search` | Searches tracks before adding to queue. | Track discovery |
| `/pause` | Pauses current track. | Temporary stop |
| `/resume` | Resumes paused track. | Continue playback |
| `/skip` | Skips current song or moves forward. | Queue flow |
| `/previous` | Returns to previously played track. | Replay previous |
| `/replay` | Restarts current track from beginning. | Restart track |
| `/stop` | Stops playback and clears current session. | End session |
| `/join` | Joins your voice channel. | Voice connect |
| `/disconnect` | Leaves voice channel. | Cleanup |
| `/queue` | Displays queue and playback status. | Queue check |
| `/move` | Moves a song in queue. | Queue management |
| `/remove` | Removes a specific queued song. | Queue cleanup |
| `/shuffle` | Shuffles current queue order. | Randomize |
| `/loop` | Sets repeat mode. | Loop control |
| `/clear` | Clears upcoming queue. | Reset queue |
| `/volume` | Adjusts playback volume. | Volume control |
| `/seek` | Jumps to a time position in current track. | Track navigation |
| `/filters` | Applies playback filter presets. | Sound shaping |
| `/equalizers` | Applies equalizer profile. | Tone control |
| `/autoplay` | Enables/controls automatic follow-up playback. | Continuous play |
| `/247` | Keeps player connected where supported. | Always-on rooms |
| `/help` | Shows command help. | Navigation |
| `/support` | Returns support links. | Help |
| `/invite` | Returns invite link. | Server setup |
