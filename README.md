## About

Afterparty Groovy Music is a free-first Discord music bot with modern playback, queue management, filters, playlists, Spotify, Apple Music, SoundCloud support, and interactive controls.

Groovy+ is an **optional supporter membership** that helps fund hosting, uptime, development, and community recognition. All normal music features remain free.
