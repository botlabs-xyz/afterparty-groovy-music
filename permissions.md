## Permissions Guide

### View Channels

Lets the bot see text and voice channels where commands are used.

### Connect

Required to join voice channels.

### Speak

Required for audio output.

### Send Messages

Required for command responses and status updates.

### Embed Links

Used for rich response formatting and queue/status cards.

### Read Message History

Helps with command context in active channels.

### Use Slash Commands

Required for `/` command usage.

## If Playback Fails

Check both:

1. **Server Settings → Roles → Afterparty Groovy Music**
2. Voice/text channel-level permission overrides
